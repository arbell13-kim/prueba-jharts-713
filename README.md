# JHARTS — Tu acompañante

Acompañamiento empático. No sustituyo a las personas, te ayudo a llegar a ellas.

Una aplicación web progresiva (PWA) de acompañamiento emocional que detecta el nivel
de riesgo de lo que escribes, te responde con empatía y te conecta con ayuda
profesional o de emergencia cuando la necesitas.

## Características

- 💬 Chat empático con detección de nivel de riesgo (bajo, moderado, alto, emergencia)
- 🆘 Botón de emergencia de doble pulsación
- 😨 Botón de ataque de pánico con acompañamiento por audio
- 🎨 Personalización de colores y temas
- 🌙 Modo claro/oscuro
- 🌐 Español e inglés
- 📱 Instalable como app (PWA)
